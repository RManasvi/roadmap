## 📊 90-Day Data Analyst Roadmap Tracker

A personal learning tracker built with Next.js to follow a structured 90-day journey from Python basics to Data Analytics, Product Analytics, and Machine Learning.

### 🚀 Features
- 📅 90-day structured roadmap (4 phases)
- ✅ Daily task tracking with progress & streaks
- 🔍 Search & filter by phase/topic
- 📊 Progress bars and completion stats
- 📚 Curated learning resources (YouTube, Kaggle, SQL, etc.)
- 💾 LocalStorage-based (no backend required)

### 🛠 Tech Stack
- Next.js 15 + TypeScript
- Tailwind CSS
- LocalStorage
